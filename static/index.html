这个平台是什么

      
它不是"又一堆节点"，而是 ai-xiaoshuo-skill 的执行台：手册的工作流就是平台的流程，
      手册的原文指令就是平台的提示词，手册的清单就是平台的检查项。

      

        
知识库
13 个模块 / 约 35 万字内置在平台里（app/knowledge/data），可浏览、检索、抽指令块

        
流程
长篇开新书 9 步 / 完本中篇 10 步 / 短篇工业化 8 步 / 番茄短故事 8 步（严格照手册），另有卡文急救工具箱

        
短故事
按番茄发布页规格：单篇完结、正文 ≥6000 字、作品分类（主分类必选 / 最多 8 个）、试读比例、是否使用 AI；一键建 5 章骨架 → 逐章生成 → 合并预览 → 导出投稿包

        
指令
每步按「模块 + 关键词」自动抽取手册原文（不改写），连同一句话出处一起注入提示词

        
检查
黑名单预检（03 模块）、违禁词与 AI 痕迹（01/02d 模块）、投稿前自查清单（01 模块）

        
模型
任意 OpenAI 兼容接口（含流式/关思考/跳过代理）；无 API 时用网页版人工通道

      

      
推荐使用路径

      
    
        
  1. 模型：加一个 API 模型并点「测试」；或加一个网页版通道。
    2. 
        
  2. 写作流程：新建书 → 从第 1 步「选题定方向」开始，点「🤖 交给模型执行本步」；产出不满意可以直接改，改完保存。
    3. 
        
  3. 第 2 步「合规预检」会跑黑名单与违禁词；人设定稿后建议锁定，之后的生成就不会覆盖它。
    4. 
        
  4. 章节：到第 7 步时逐章生成；生成完用「去 AI 味改写」，然后「导出成稿」。
    5. 
        
  5. 合规检查：投稿前跑三条检查；知识库随时查手册原文。
    6. 
        
  6. 写短故事：进「短故事」页签 → 填名称+主分类（可再加次分类）创建 → 「建立 5 章骨架」→ 逐章「⚡ 一键写完本章」或「一键写完所有章」→ 「预览全文」看字数与发布项 → 「导出投稿包」（正文-粘贴用.txt / 发布信息卡.txt / .docx）。
    7. 
      

      
⚠️ 手册铁律（平台不再重复提醒）：纯 AI 稿不能直接投稿，必须人工打磨校验；
      违禁词与违规情节是最高优先级；范文与案例只做参考，禁止照抄投稿；同人内容仅供个人练习。
