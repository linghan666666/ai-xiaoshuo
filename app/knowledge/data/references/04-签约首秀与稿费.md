（一）签约机会限制：单部长篇小说仅拥有3 次正式签约评估机会，分别在
作品满2万字、5 万字、8 万字时解锁，前一次评估失败，才会解锁下一次机会；
三次全败，该作品永久失去签约资格，无法再次申请。
关键避坑：因敏感词、格式混乱等安全审核问题被打回，修改后重提不占用
签约次数；只有编辑评估环节，因故事性、主线、节奏等问题被拒，才会消耗一

长篇网文：2 万字解锁首次签约申请入口，是平台主流品类，享受全勤、分

这是新人签约的第一道选择题，选错直接浪费时间、消耗创作热情，我把两

（一）直发（后台直接发布申请）
定义：在番茄作家助手/电脑端作家后台创建新书，填写书名、简介、分类，
正常发布章节，达到对应字数门槛后，直接在后台点击「申请签约」，走平台系
统+编辑的标准化审核流程。
完整操作流程：完成账号实名认证，创建新书，正确选择作品分类、标签，
完善书名、简介、封面；正常发布章节，累计字数达到2 万字，后台解锁「申请
签约」按钮；点击申请，先进入安全审核环节（2-5个工作日），核查敏感内容、
格式、合规性，不通过可修改重提；安全审核通过后，进入编辑评估环节（2-5

定义：通过番茄官方公布的各赛道编辑收稿邮箱，将你的作品信息（书名+

适合人群：写小众赛道、脑洞文、慢热强剧情作品的作者；有一定写作基础，

三、2026番茄最新签约条件（硬性门槛+核心评估标准）
很多新人以为凑够字数就能签约，大错特错！番茄签约分「必达硬性门槛」
和「核心评估标准」，前者是入场券，后者决定你能不能过稿。
（一）必达硬性门槛（一条不满足，直接无缘签约）
合规性要求：作品必须为原创独家首发，无抄袭、融梗、版权瑕疵，未在其
他平台发布过；不涉及平台红线题材，无低俗色情、暴力血腥、违规时政、学生
负面导向等违禁内容。
字数门槛：长篇网文作品满 2 万字，可发起首次签约申请；短故事作品满
6000字，可申请签约。
账号要求：作者账号完成本人实名认证，年满 18周岁，无平台违规封禁记
录，一个身份证仅能绑定一个签约账号。
格式要求：章节排版规范，无大段无换行内容，无乱码、大量标点符号堆砌、
章节重复、恶意水文等问题。
（二）核心签约评估标准（编辑过稿的核心打分项）
满足硬性门槛后，编辑全靠这 5 个维度评估你的作品能不能签，也是 AI写
文优化的核心方向：
开篇节奏：黄金三章必须有核心冲突、金手指亮相、主角目标确立，番茄是
免费阅读平台，极度看重开篇抓客能力，节奏拖沓、3章还没进入主线的作品，
大概率被拒。
题材适配：作品符合平台收稿方向，赛道标签精准，热门赛道作品需有差异
化亮点，冷门赛道作品需有清晰的受众群体，严禁踩平台红线题材。
故事主线：主线清晰明确，主角有强目标感，剧情推进有逻辑，爽点密集且
有预期，无主线混乱、剧情跳脱、人设崩塌等问题。
原创性要求：2026年平台升级了AI 原创度检测+人工抽检双机制，作品需满
足平台原创度标准，大量洗稿、同质化、AI流水账内容，直接被拒。

商业价值：作品具备持续更新能力，剧情有长线发展空间，符合免费阅读用
户的阅读习惯，有高追读、高完读的潜力，这是平台签约的核心考量。
四、签约合同核心注意事项&避坑指南
能签约是好事，但合同千万不能闭着眼签！番茄的签约合同是平台强势的全
版权独家授权协议，这几个核心坑点，新人一定要提前看清，避免踩坑后悔莫及。
（一）核心版权条款：全版权独家授权
核心条款：签约后，你将作品的全球范围内、全版权独家授权给平台，包括
但不限于信息网络传播权、复制权、出版权、改编权（短剧、影视、动漫、音频
等）、汇编权等所有著作财产权。
避坑提醒：这意味着，签约后你无权自行将作品授权给其他平台、机构，所
有版权衍生操作，都必须经过平台同意，包括你自己想改编短剧、出书，都不能
私下操作。
授权期限：常规合同授权期限为协议生效之日起至著作权财产权保护期届满
（即作者终身+去世后50年），部分合同为固定20年期限，远超行业常规的5-10
年授权期。
避坑提醒：签约前务必看清授权期限，一旦签约，哪怕平台后续不给你的作
品流量、不做推广，你也无权收回版权，无法转投其他平台，切勿抱着“能签就
行”的心态忽略这条。
（二）收益分成条款：看清分成范围与核算规则
基础分成：番茄独家分成签约作品，广告/听书分成基础比例为作者 55%，
平台45%，符合条件的作品可叠加专项激励、全勤奖、星火计划等福利，具体以
平台最新福利政策为准。
避坑提醒：全勤奖、星火奖励等均有明确的更新要求、数据门槛，不是签约
了就能拿，签约前务必看清 2026 年最新作家福利规则，避免因断更、字数不达
标错失奖励番茄小说网。
衍生收益：短剧、影视、出版等版权衍生收益，合同中会单独约定结算规则，
常见为一次性买断或分账模式，并非和基础分成同比例，签约前务必看清衍生收
益的分成比例、结算周期。
（三）解约与违约责任：不对等条款重点关注

单方解约权：合同中绝大多数解约条款，均为平台单方解除权，平台可因你
违规、断更、作品数据不达标等多种理由解除合同；但作者几乎没有主动解约的
渠道，哪怕你想停更、放弃作品，也无法单方面解约，强行停更可能构成违约。
避坑提醒：签约前务必看清解约条款，切勿签约后随意断更、删除章节、将
作品发布到其他平台，这些行为均构成违约，平台有权追回已发放的稿费，甚至
追究你的赔偿责任。
违约追责：若作品出现抄袭、融梗、版权纠纷，所有法律责任和赔偿责任，
均由作者本人承担，平台有权追回全部收益，并要求作者赔偿平台因此遭受的全
部损失，签约前务必确保作品100%原创，无任何版权瑕疵。
（四）其他高频坑点
AI训练授权条款：2026 年合同中大概率包含「签约作品可用于平台AI 模型
训练」的相关条款，意味着你的作品文字、风格可能被用于平台 AI 训练，签约
前可重点关注，若有异议可提前与编辑沟通。
笔名与账号约束：签约后，你的签约笔名对应的账号，需遵守平台规则，部
分合同会约定笔名的独家使用权，切勿随意出借、售卖签约账号，避免产生法律
纠纷。
信息匹配问题：填写合同信息时，务必确保手机号、银行卡均为本人身份证
办理，携号转网、新办手机号需等待运营商信息同步，否则会出现认证不匹配，
导致签约失败。
最后说两句
番茄是对新人最友好的网文平台之一，低门槛、高流量、变现路径清晰，但
不代表盲目写就能签约赚钱。不管是直发还是内投，核心永远是打磨好作品，贴
合平台规则和用户喜好；签约前一定要看清合同条款，明白自己签的是什么，放
弃的是什么，不要为了一个签约名额，盲目签下影响自己十几年的“卖身契”。

第1-5条：番茄签约高频拒稿核心（拒稿反馈对应项）
1. 主线不清晰，核心叙事逻辑混乱
通用拒稿表现：
•长篇：多支线并行、主次不分，主线跑偏，读者抓不住核心目标
•短篇：无明确主线，三线并行（离婚+搞事业+恋爱）无重点
番茄规则依据：
平台要求所有签约作品「主线贯穿始终，支线服务主线」，长篇需明确核心成长/逆
袭目标，短篇必须是「单主线闭环叙事」，禁止无意义多线并行。
分赛道专属修改方案：
•现代言情：锁定1条核心线，感情线/配角线依附主线，不单独开支线
•古代言情：留1条主线（宅斗/宫斗/重生），家族/权谋只做辅助
•玄幻仙侠：明确升级/复仇/寻亲主线，情缘/秘境服务主线
•悬疑灵异：紧扣1桩核心案件，支线小案子铺垫主线真相
•青春校园：锁定恋爱/成长/逆袭主线，同学/家庭问题做助推
•年代文：固定种田/经商/知青主线，邻里/感情线不脱离搞钱核心
•短剧风短篇：单主线闭环，只走「受辱—反击—打脸」，无多余支线
2. 开篇无矛盾冲突，无法快速抓住读者
通用拒稿表现：
•开篇大段环境/心理铺垫，几百字无冲突，节奏平淡
•冲突太弱（夫妻冷战/宅斗小摩擦），无强刺激，读者无代入感
番茄规则依据：
平台以「开篇留存率」为核心考核，黄金300字/三章内必须有「强冲突/强困境/强
悬念」，快速建立代入感。
分赛道专属修改方案：
•现代言情：开篇上离婚/当众羞辱/白月光上门等高冲突名场面
•古代言情：开篇写被陷害/休弃/入宫遭构陷/重生即危机
•玄幻仙侠：开局被退婚/废修为/驱逐/秘境遇险/背叛
•悬疑灵异：开篇撞见怪事/接诡异委托/住凶宅/卷入命案

3. 叙事节奏拖沓，无有效情节推进
通用拒稿表现：
•长篇：章节注水，无意义对话/描写凑字数，几十章无转折/爽点
•短篇：铺垫过长，几千字才到核心冲突，不符合快节奏需求
番茄规则依据：
节奏拖沓导致留存率暴跌，签约审核重点考察「叙事节奏与情节推进效率」。
分赛道专属修改方案：
•现代言情：每章有小转折，2章1个小爽点，无冗长回忆/心理
•古代言情：每章挖坑/冲突/反转，宅斗见招拆招，不写景唠嗑
•玄幻仙侠：升级/刷怪/打脸紧凑衔接，不写无意义宗门日常
•悬疑灵异：每章抛新线索/悬念，快速推进解谜，不拖沓氛围
•青春校园：跳过无关日常，聚焦暧昧/误会/逆袭关键节点
•年代文：直奔搞钱主线，邻里拉扯点到为止，不冗长家长里短
•短剧风短篇：300字冲突、800字转机、1500字打脸，全程高能
4. 无效描写过多，无信息增量（注水）
通用拒稿表现：
•场景描写：大段环境/建筑/服饰，不推动情节、不塑造人设
•心理描写：无意义情绪宣泄，不服务角色/情绪
•外貌描写：堆砌形容词，无身份/性格反差
番茄规则依据：
禁止「无信息增量的冗余内容」，所有描写需承担推动情节/塑造人设/铺垫伏笔/强
化情绪的作用。
分赛道专属修改方案：
•现代言情：少写无关装潢，外貌突出反差，心理只留推动剧情部分
•古代言情：精简服饰/庭院描写，景物烘托宅斗氛围
•玄幻仙侠：省略重复写景，功法/法器只写关键设定
•悬疑灵异：氛围点到为止，靠事件/细节带感，不渲染恐怖
5. 章节钩子不足，读者追更意愿低
通用拒稿表现：

•章节结尾平淡无悬念，读者无追更欲望
•钩子太弱，无法激发读者好奇心
番茄规则依据：
签约及推荐重点关注「追更率」，章节结尾必须有明确“追更动力点”。
分赛道专属修改方案：
•现代言情：情敌搞事/前夫反悔/身份将曝光/意外怀孕
•古代言情：庶妹下毒/帝王猜忌/重生秘密将暴露/家族阴谋浮出水面
•玄幻仙侠：遇强敌/秘境至宝/仇人上门/修为突破关键
•悬疑灵异：发现诡异线索/身边人不对劲/下一个受害者将出现

（三）税务常见疑问（官网答疑，大白话解答）

2. 疑问2：平台代扣个税，会给我提供完税证明吗？ → 解答：会，每
年1月，平台会为作者提供上一年度的个税完税证明，可在作家助手后台下

3. 疑问3：如果平台忘了代扣个税，我需要自己补吗？ → 解答：不需

需自行操作，若有疑问可联系官方客服；
4. 疑问4：个税可以申请退税吗？ → 解答：可以，每年3-6月，作者

三、提现+税务坑点（官网明确，必避！否则少拿钱/提现失败）
1. 坑点1：绑定非本人银行卡 → 后果：提现失败，无法到账，官网禁
止绑定非本人银行卡，需绑定与实名认证一致的银行卡；
2. 坑点2：认为“提现金额就是税前稿费” → 后果：误以为平台扣
钱，实际提现金额已扣除个税，可在稿费明细中核对税前金额、个税金额；
3. 坑点3：同一自然月多次提现，忽略累计个税 → 后果：平台会累计
计算个税，可能出现“单次提现个税少，多次提现累计个税增加”的情况，属
于正常现象；
4. 坑点4：未及时实名认证/银行卡过期 → 后果：提现失败，稿费无法
到账，需及时更新实名认证信息、更换有效银行卡；
5. 坑点5：违规获得的收益提现 → 后果：提现申请被驳回，违规收益
被没收，账号可能被封禁，甚至影响后续稿费发放；
6. 坑点6：混淆不同收益类型的税务标准 → 后果：误以为税务计算错
误，其实是不同收益类型扣除比例不同，可对照官网收益分类及税务标准核
对；
7. 坑点7：提现后未及时查看到账情况，银行卡异常未发现 → 后果：
稿费到账失败，需联系银行和平台客服处理，延误到账时间。
