# 番茄 AI 网文创作全流程

## 用途

把 `D:\ai小说` 那一整套番茄小说 AI 写作课程资料（131 个文件、约 38 万字）整理成可直接调用的模块化知识库。
本 skill 是这套资料的**唯一入口和检索地图**：用户提到写小说 / 番茄 / 网文相关任务时，按下方路由表读取对应 `references/` 文件，而不是凭空回答。

## 何时使用

- 用户要开新书、定选题、起书名、写简介、写大纲、设人设
- 用户要写 / 改 / 续写具体章节，或抱怨「AI 味重」「人设崩了」「卡文」
- 用户问签约、内投、首秀数据、更新节奏、稿费提现
- 用户要检查稿件有没有踩违禁词、违规情节、审核风险
- 用户写短篇（8000-25000 字）或同人文
- 用户问「资料里怎么说」「课程里那个指令是什么」

### 第二步：需要精确措辞时，直接用原文

`references/` 里带 `## 📄 原文件名` 的小节就是课程原文摘录。资料的核心价值是**可直接复制粘贴给 AI 的指令（prompt）**。
用户要指令时，把原文的指令块**原样**给出，不要自己重写压缩——那些指令的措辞是反复调过的。

### 第三步：检索大文件

`03-选题与开篇模板库.md`（约 10 万字）和 `04-签约首秀与稿费.md`（约 4 万字）较大，用关键词检索而不是通读：

```bash
# 在 skill 目录下检索
grep -n "关键词" references/03-选题与开篇模板库.md
```

`scripts/extract_material.py` 可在 `D:\ai小说` 资料更新后重新抽取全部文本。

## 核心工作流（蒸馏版）

### A. 长篇网文开新书

1. **选题**：先查 `03` 的「绝对不能碰题材黑名单」，再按 `02a` 的选题指令定方向（找流量、避烂大街）
2. **合规预检**：过一遍 `01` 的违禁词清单 + 违规情节自查表，确认题材本身不触线
3. **书名 / 简介**：套 `03` 的书名公式 + 简介公式，从 100 个参考案例里找同赛道的对标
4. **人设档案**：先做人设档案（`05` 的人设档案锁死法），**先锁人设，再写正文**
5. **大纲**：`02a` 故事大纲指令搭框架定节奏
6. **黄金三章**：`02a` 开篇黄金 3 章指令 + `03` 开篇公式与 50 个爆款开头范文
7. **章节续写**：`02a` 续写指令 + 对应赛道专属指令（`02b`/`02c`）
8. **去 AI 味**：`02d` 万能去 AI 味指令 + `05` 去 AI 化 8 法
9. **投稿前**：`01` 投稿自查核对清单逐项过

### B. 番茄短篇（8000-25000 字）

严格按 `06-短篇工业化手册.md` 的 8 步流水线走，不跳步；黄金五段叙事结构 + 四大题材模板；终稿用「投稿终稿核验清单」逐项核对。

发到番茄「短故事」入口时，发布规格（6000 字机会线、章节标题划分、作品分类最多 8 个、试读比例、是否使用 AI）按 `14-番茄短故事.md` 执行。

### C. 卡文 / 人设崩坏急救

读 `05` 的「卡文快速自检清单」，再针对症状选法：人设崩 → 人设档案锁死法 / 行为红线阈值法 / 对话风格锁死法；AI 味重 → 去 AI 化 8 法里对症状的那一条。

## 铁律（每次都要守）

1. **纯 AI 稿不能直接投稿**。平台严查，必须人工打磨校验；发布时按平台要求勾选「使用 AI」声明。
2. **违禁词 / 违规情节是最高优先级**。任何正文产出后，都要用 `01` 的清单过一遍；一级违禁词命中即永久封禁，且**不要用谐音、拆字、空格规避**——算法能识别变体，规避失败直接升级处罚。
3. **范文与案例只做参考，禁止照抄投稿**，会被判定洗稿。
4. **同人内容仅供个人练习**，原著 IP 有版权风险，不得商用投稿或出版。
5. **资料为 2026 年版本**。平台规则、违禁词库、稿费口径会变，涉及金额与规则的结论要提示用户「以番茄作家助手 / 官方后台最新公示为准」。
6. **不擅自改用户的正文**：只在用户明确要求时才动稿；改稿按「先指问题、再给建议、由用户定」的顺序。
